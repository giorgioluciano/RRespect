Comparing ReSpectR Results to Python

Overview

This vignette computes fresh ReSpectR results in-memory (no file writes) and compares them against packaged Python reference summaries.

Reference tables are distributed with the package in inst/extdata.

Fresh Time-Domain Comparison

ref_H_time <- utils::read.csv(file.path(base, "comparison_H_time.csv"))
ref_D_time <- utils::read.csv(file.path(base, "comparison_disc_time.csv"))

time_tests <- sort(unique(ref_H_time$test))
time_dir <- file.path(base, "time_tests")

time_current <- lapply(time_tests, function(tt) {
  dat_file <- file.path(time_dir, paste0(tt, ".dat"))
  stopifnot(file.exists(dat_file))
  cur <- run_single_test("time", dat_file)
  data.frame(test = tt, lamC_current = cur$lamC, Nopt_current = cur$Nopt)
})
time_current <- do.call(rbind, time_current)

time_compare <- merge(time_current, ref_H_time[, c("test", "lamC_R", "lamC_PY")], by = "test")
time_compare <- merge(time_compare, ref_D_time[, c("test", "Nopt_R", "Nopt_PY")], by = "test")

time_compare$lamC_rel_diff_vs_PY <- abs(time_compare$lamC_current - time_compare$lamC_PY) /
  pmax(abs(time_compare$lamC_PY), .Machine$double.eps)
time_compare$lamC_rel_diff_vs_archived_R <- abs(time_compare$lamC_current - time_compare$lamC_R) /
  pmax(abs(time_compare$lamC_R), .Machine$double.eps)
time_compare$Nopt_delta_vs_PY <- time_compare$Nopt_current - time_compare$Nopt_PY
time_compare$Nopt_delta_vs_archived_R <- time_compare$Nopt_current - time_compare$Nopt_R

Notes

  • This vignette does not write output files; all current ReSpectR results are computed in-memory via writeOutput = FALSE.
  • Python raw output vectors are not distributed in the package, so fresh similarity is assessed against packaged Python reference summary metrics (lamC_PY, Nopt_PY) and drift versus archived R reference columns.
